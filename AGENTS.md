# Project guidance

- `fastgpu` is a Go CLI that manages RunPod GPU environments, persistent storage, SSH/VS Code access, file transfers, and model inference.
- The developer's goal is to make a remote GPU feel like an extension of the local computer while preserving user data and keeping infrastructure under explicit user control.
- This repository is public. Never commit or expose API keys, tokens, private keys, credentials, or sensitive personal/account data in source, documentation, examples, or logs. Use placeholders in examples.
- Write code only when explicitly requested. Keep changes minimal and ask before making additional fixes.
- Always write in english in the code.
